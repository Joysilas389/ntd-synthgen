Public Health Informatics · v1.0

Modular synthetic data generation for neglected tropical diseases.

A privacy-preserving, modular engine that learns from imperfect health data and produces realistic synthetic tabular records for outbreak modelling, epidemiological research, and policy simulation in low-resource environments across Sub-Saharan Africa.

Get started How it works
01

Modular by disease

Three pre-built modules — water-borne, vector-borne, skin NTDs — each with its own schema, constraints, and seed data. Add a new disease by dropping a folder.

02

Privacy-first

The engine learns the joint distribution and emits synthetic records that preserve statistical structure without retaining individual rows. Useful where surveillance data cannot be shared directly.

03

Conditional generation

Sample by region, climate band, or sanitation index. Generate rare-region scenarios for outbreak planning where no data exists.

Pipeline

From small dataset to deployable synthetic cohort.

The five steps

  1. Upload a CSV — or use the bundled seed dataset.
  2. Select a disease module to inherit schema and constraints.
  3. Train the synthesizer (Gaussian copula on PIT-transformed marginals).
  4. Generate N synthetic rows, optionally conditioned on region or climate.
  5. Validate using KS, Wasserstein, correlation Frobenius, and TSTR.

Notes

Why this matters in low-resource settings.

Real-world NTD surveillance data is fragmented, under-reported, and frequently restricted by privacy and infrastructure constraints. This system does not replace surveillance — it is a tool for downstream modelling, training set augmentation, and scenario simulation in environments where data scarcity blocks even basic ML feasibility studies.
